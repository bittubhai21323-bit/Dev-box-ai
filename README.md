# DevBox AI v11 🤖📱
An all-in-one Android power tool, voice assistant, and security workstation.

## 🚀 Features
- **AI & Voice**: Multilingual AI Chat, Wake-word ("Hey DevBox"), Voice Control (100+ languages), TTS.
- **Phone Control**: Accessibility automation (Open apps, Back, Home, Volume, Flashlight).
- **Security**: App Blocker, Process Guardian, Root Ops, Risky App Scanner.
- **APK Modder**: Decompile, Edit (Smali/XML), Rebuild, Zipalign, Sign (with `apktool` & `apksigner`).
- **Productivity**: Journal, Reminders, Routines, Tasks.
- **Files & Dev**: SAF File Manager, ZIP Ops, CLI Tools (nmap, sqlmap, git, etc.).
- **Self-Heal**: Auto Backup (AES-256), Crash Reporter, Auto Update.
- **Firebase**: Live Remote Control, Remote Config, FCM Push.
- **Setup**: Self-configuring Firebase (No `google-services.json` required).

## 🛠️ Setup
1. Clone the repo.
2. Open in Android Studio.
3. Sync Gradle.
4. Install Termux & grant permissions.
5. Build & Run.

*Developed for power users. Use responsibly.*
